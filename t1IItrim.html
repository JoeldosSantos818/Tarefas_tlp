CSS - Cascading Style Sheets

CSS é uma linguagem de estilo utilizada para descrever a apresentação de documentos HTML. Com o CSS você controla cores, fontes, espaçamentos, layouts e muito mais!

🎨 O Poder do CSS

CSS separa o conteúdo (HTML) da apresentação (estilo), permitindo que você crie sites visualmente incríveis com menos código e maior flexibilidade.

Seletores CSS

Seletores são padrões usados para selecionar os elementos HTML que você deseja estilizar.

Seletor por Tag

Seleciona todos os elementos de um determinado tipo.

p {
  color: blue;
}

Seletor por ID

Seleciona um elemento específico com um id único.

#header {
  background-color: #333;
}

Seletor por Classe

Seleciona todos os elementos com uma classe específica.

.destaque {
  font-weight: bold;
}

Propriedades Principais

As propriedades CSS definem como os elementos selecionados serão estilizados.

Cores e Fundos

Controle cores do texto, fundos e gradientes.

.elemento {
  color: #ffffff;
  background-color: #D32F2F;
}

Tipografia

Defina fontes, tamanhos, pesos e espaçamentos.

h1 {
  font-family: 'Arial', sans-serif;
  font-size: 2.5rem;
}

Box Model

Controle margin, padding, border e box-sizing.

.caixa {
  margin: 20px;
  padding: 15px;
  border: 2px solid #333;
}

Técnicas de Layout

Flexbox

Modelo unidimensional para criar layouts flexíveis e responsivos.

.container {
  display: flex;
  justify-content: center;
  align-items: center;
}

CSS Grid

Sistema bidimensional para criar layouts complexos.

.grid-container {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 20px;
}

Position

Controle de posicionamento: relative, absolute, fixed e sticky.

.menu-fixo {
  position: fixed;
  top: 0;
  width: 100%;
}

Design Responsivo

Media Queries

Adapte o layout para diferentes tamanhos de tela.

/* Para telas menores que 768px */
@media (max-width: 768px) {
  .coluna {
    width: 100%;
  }
}

Unidades Flexíveis

Use unidades relativas como %, vw, vh, rem e em.

.container {
  width: 90%;
  max-width: 1200px;
  margin: 0 auto;
}

Viewport

Meta tag essencial para sites responsivos.


<meta name="viewport"
  content="width=device-width, initial-scale=1.0">
